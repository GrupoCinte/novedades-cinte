# Conector CINTE (extensión Chrome)

Permite guardar la sesión de **El Empleo** y **LinkedIn** desde el portal Atracción de Talento, sin usar terminal.

## Instalación (una vez)

1. Abra Chrome → `chrome://extensions`
2. Active **Modo de desarrollador** (arriba a la derecha)
3. Pulse **Cargar descomprimida**
4. Elija esta carpeta: `integrations/cinte-session-bridge`
5. Recargue el portal CINTE (F5)

## Uso

1. Portal → Atracción → Integraciones
2. **1. Conectar cuenta** (abre El Empleo o LinkedIn)
3. Inicie sesión en esa pestaña
4. Vuelva al portal → **2. Guardar conexión**

Si el conector no aparece detectado, recargue la página del portal tras instalar la extensión.
